┌──────────────────────────────────────────────────────────────────────────────┐
│ 🗄️ WHAT'S IN THE DATABASE                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

  Tables:
    • players         → All registration data (name, role, stats, photos)
    • announcements   → System announcements
    • settings        → Configuration (registration open/close, etc.)

  Functions:
    • get_registration_stats()     → Get all statistics
    • find_player(search_term)     → Search by ID or reg_no

  Storage:
    • player-photos   → Photo storage bucket

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔍 USEFUL SQL QUERIES                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  View all players:
    SELECT * FROM players ORDER BY created_at DESC;

  Count by role:
    SELECT primary_role, COUNT(*) FROM players GROUP BY primary_role;

  Today's registrations:
    SELECT * FROM players WHERE created_at::date = CURRENT_DATE;

  Search player:
    SELECT * FROM find_player('VJTI-CRK-1234');

  Get statistics:
    SELECT get_registration_stats();

┌──────────────────────────────────────────────────────────────────────────────┐

  Identity:
    • Full name (e.g., "Virat Kohli")

    • Primary role (Batter/Bowler/Wicketkeeper)

    • Past experience (up to 1000 chars)

  Contact:
    • WhatsApp number (+91XXXXXXXXXX)

  Photo:
    • Profile picture (base64, ~375KB)

  Metadata:
    • Registration ID (VJTI-CRK-XXXX)
    • Public token (for sharing)
    • Timestamps (created_at, updated_at)
    • Status (registered/shortlisted/selected)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Registration fails:
    → Check .env has correct Supabase credentials
    → Run: npm run test:db
    → Check browser console (F12)
    → Check Supabase logs (Dashboard → Logs)

  Tests fail:
    → Verify .env file updated
    → Ensure SQL script ran successfully
    → Check Supabase project is active (not paused)

  Photo not uploading:
    → Max size: 5MB
    → Formats: JPEG, PNG, WebP
    → Check browser console

  Dashboard shows no data:
    → Register at least one player first
    → Verify organizer is logged in
